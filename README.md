# genpark-agent-meeting-intelligence-action-extractor-skill

Autonomous executive meeting intelligence parser extracting structured action items, owner assignments, deadlines, and dependency risk scores.

## Architecture
- **Input**: Conversational transcripts, audio notes, and agenda summaries.
- **Engine**: Pure Python standard library linguistic entity matcher & deadline parser.
- **Output**: JSON action items, priority tags, and timeline feasibility telemetry.
